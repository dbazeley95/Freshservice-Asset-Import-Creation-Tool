Help Guide

1. Pick an asset type

Use the menu on the left (or the "Asset Type" button on mobile) to choose what you're importing — Monitor, Laptop / PC, Desktop PC, Tablet, or Interactive Touchscreen. Types marked "Coming soon" don't have an import template wired up yet.

2. Fill in General

Pick a Company / Location Preset to fill both fields at once, or type your own. These are copied onto every row you add, and each row can still be edited individually afterwards.

3. Fill in Hardware Specific

Fields marked with a red * are required. Start typing in Product to see suggestions, or narrow them first with the Manufacturer dropdown above it. Picking a known product auto-fills its Warranty and other specs.

4. Bulk Add from Serial Numbers

Paste one asset per line into the box:

  • A bare serial number — the Name will default to the Asset Tag
  • Name, Serial (or paste two columns from a spreadsheet) to set the name yourself

Or click Import CSV to load a Name/Serial file directly — use Download Template first if you're not sure of the format.

5. Asset Tag

Generated automatically as <site code>-<serial> from the Company you've selected — you never type it by hand.

6. Rows table & multiple models

Added rows accumulate in the table below, where you can fine-tune any field per row. To include another model in the same export, change the Product/Hardware Specific details above and click Add Rows from Serials again before downloading.

7. Download CSV

Produces a CSV with the exact column order Freshservice expects for the selected asset type, ready to import.

Editing an existing export

Import CSV for Editing, above the Rows table, loads a full CSV — every column, not just Name/Serial — straight into the table so you can tweak an export you already made and re-download it. It matches columns by header text, so unrecognised columns are ignored and missing ones are left blank; imported rows are added alongside whatever's already there.

Your data

Everything stays in this browser's local storage on this device — nothing is uploaded anywhere. Closing the tab is safe; clearing site data is not.
