Compiled 18 Aug 2026

Closing the tab won't lose your work, but clearing site data will.

Help Guide

Theme

The Theme dropdown (in this Settings & Help menu, opened from the gear icon top-right) switches between System (follows your OS/browser setting), Light, Dark, and five retro skins — Vista, Classic Mac, XP, Windows 3.1, and Matrix — each a full visual reskin rather than just a color swap. Matrix also animates a dimmed, throttled falling-character canvas behind everything; it pauses when the tab isn't visible and skips entirely if you have reduced motion enabled system-wide. Your choice is remembered and applied before the page paints on your next visit.

1. Pick an asset type

Use the menu on the left (or the "Asset Type" button on mobile) to choose what you're importing — Monitor, Laptop, Desktop, iPads / Tablets, Interactive Touchscreen, Wi-Fi Access Points, Network Switches, Phones & Telephony, Printers & Copiers, Servers, Docking Stations, or Other Devices. A note at the bottom of the list points at Leave Feedback for requesting any type that isn't here yet.

2. Fill in General

Company and Location are both dropdowns, not free text. Company lists every known site; picking one narrows Location down to just that site's own sub-locations, defaulting to the site's own name until you pick something more specific. These are copied onto every row you add, and each row can still be edited individually afterwards.

3. Fill in Hardware Specific

Fields marked with a red * are required. Start typing in Product to see suggestions, or narrow them first with the Manufacturer dropdown above it. Picking a known product auto-fills its Warranty and other specs.

4. Bulk Add from Serial Numbers

Paste one asset per line into the box:

  • A bare serial number — the Name will default to the Asset Tag
  • Name, Serial (or paste two columns from a spreadsheet) to set the name yourself

Asset types with an extra per-device field (currently Phones & Telephony's Extension) accept it as a trailing value on the same line — Name, Serial, Extension — instead of one shared value copied onto every row; leave it off a line if you don't have it yet.

Or click Import CSV to load a Name/Serial file directly — use Download Template CSV first if you're not sure of the format.

If a bare-serial line shows up alongside Name, Serial lines, it's marked with ⚠ in the preview and Rows table — usually a forgotten comma, so double-check the Name before downloading. Editing that row's Name clears the warning.

5. Asset Tag

Generated automatically as <site code>-<serial> from the Company you've selected — you never type it by hand.

6. Add Assets of Another Product

Its live preview shows exactly what clicking the button will add to the Rows table below. Rows accumulate rather than replacing what's there — to mix another product into the same export, change the Product/Hardware Specific details above and click Add Assets of Another Product again before downloading. Each export can hold up to 10 different products; you can fine-tune any field per row afterwards.

7. Download CSV

Produces a CSV with the exact column order Freshservice expects for the selected asset type, ready to import. If any rows are missing required fields, a red count stays next to the row total in Rows until they're fixed — not just a one-time warning when you click Download. Once you've downloaded, an Open Freshservice to Import button appears alongside it — it opens the Freshservice CMDB Items list in a new tab, which is where Freshservice's own Import button lives (it's a popup, not a page of its own, so this is as close as a link can get you).

Editing an existing export

Import Populated CSV for Editing, above the Rows table, loads a full CSV — every column, not just Name/Serial — straight into the table so you can tweak an export you already made and re-download it. It matches columns by header text, so unrecognised columns are ignored and missing ones are left blank; imported rows are added alongside whatever's already there.

Warranty Lookup

A row whose Product matches a known Dell or Apple model — and Hardware Specific's shared defaults, the same way — gets a Look up Warranty button. Give it a Serial Number/Service Tag and it fills in Acquisition Date, Warranty (In Months), and Warranty Expiry Date for you. Look up Warranty for All Rows, above the Rows table, does the same for every eligible row at once — any row with a Dell/Apple Product, a Serial Number, and at least one of those three fields still missing. Check specific rows first (the same checkboxes used for bulk-editing a field) to look up just those instead of the whole table. Rows that already have all three are left alone, so it's safe to run again after adding more rows. This is the one place a Serial Number leaves this browser: it's sent to lookup.xcet.uk, a separate tool, to look that information up. More manufacturers may be added there over time.

Your data

Everything stays in this browser's local storage on this device — nothing is uploaded anywhere, except a Serial Number you submit to Look up Warranty (see above). Closing the tab is safe; clearing site data is not.

Release Notes

3.4.0

Look up Warranty Buttons Now Match the Rest

All three Look up Warranty buttons — Hardware Specific's, each row's own in the Rows table, and Look up Warranty for All Rows above it — are now a filled sherbet yellow with the same corner rounding as every other button, instead of a mix of an oddly pill-shaped nav-style button, an unfilled outline, and a plain neutral one. Same yellow across every theme, including the Vista/XP glass gradients, Mac's bordered look, and Matrix's glow.

3.3.0

A Warning Before Adding Assets That Aren't Ready

Add Assets of Another Product now speaks up instead of failing quietly. Click it with nothing pasted into Assets and it tells you to paste something first, rather than doing nothing with no explanation. Click it while required Shared Defaults are still empty (Company, Product, Asset State, and the rest) and it warns how many rows will come in missing those fields — the same check Download CSV already does — before you commit to adding them, with the option to add anyway if that's intentional.

3.2.0

Warranty Lookup Feels Faster, and Can Target Just What You've Checked

All three Look up Warranty entry points now show a busy state while a lookup is running instead of just quietly disabling — the per-row button spins, and the toolbar/popout buttons switch to "Looking up…" until it's done. Look up Warranty for All Rows also now respects the Rows table's checkboxes: check specific rows first (the same ones bulk-edit uses) and it only looks up those, instead of always hitting every eligible row in the table; leave nothing checked and it works exactly as before.

3.1.0

Warranty Lookup for All Rows at Once

A new Look up Warranty for All Rows button above the Rows table looks up every eligible row in one go, instead of clicking each row's own button one at a time. "Eligible" means a Dell or Apple Product, a Serial Number, and at least one of Acquisition Date/Warranty (In Months)/Warranty Expiry Date still missing — rows that already have all three are left untouched, so it's safe to run again after adding more rows. Requests are batched up to 20 serials per call (lookup.xcet.uk's own limit) and split by manufacturer, so a big export doesn't turn into dozens of individual round trips. The summary afterwards says how many rows were updated and lists any serials it couldn't find or that failed to look up.

3.0.1

Screenshots in Help and Release Notes

Every step of the Help guide now has a real screenshot alongside its explanation — Pick an asset type, Fill in General, Fill in Hardware Specific, Bulk Add from Serial Numbers, Add Assets of Another Product, Download CSV, and the new Warranty Lookup section. The latest Release Notes entry gets one too. Screenshots are always captured in Light theme regardless of which theme you're actually using, the same way one reference image is easier to keep accurate than seven theme variants of each.

3.0.0

Warranty Lookup for Dell and Apple

A row whose Product matches a Dell or Apple entry in the catalog now gets a Look up Warranty button in the Rows table, next to Delete — give it that row's Serial Number and it fills in Acquisition Date, Warranty (In Months), and Warranty Expiry Date directly, no more copying dates across by hand. Hardware Specific gets the same button next to Acquisition Date for the shared defaults: since there's no Serial Number field up there, it opens a small popout asking for one instead, useful when adding several units of the same model at once, since every row added afterwards from Bulk Add picks up the result automatically (it only affects rows added after using it, not ones already in the table). Either way, a row with an unrecognised Product, or no Serial Number yet, just doesn't show the button — or explains what's missing if you click it anyway. This is the one place a Serial Number leaves your browser: it's sent to lookup.xcet.uk, a separate tool, to look up that information; more manufacturers may be added there later. A "Warranty Lookup" item in the Settings & Help menu also opens that site directly in a new tab. Also fixed this app's service worker so it only caches its own files — it was previously intercepting every request including these lookups, which not only served no purpose but silently broke them.

2.3.0

Warranty Expiry Date Now Calculates Itself

Warranty Expiry Date now fills itself in as soon as Acquisition Date and Warranty (In Months) are both known — there's nothing left to work out by hand once you have both. Works no matter which order you fill them in, and works from picking a Product preset that carries its own warranty length (e.g. a 12-month or 48-month model) just as well as typing both fields yourself. Every row in the Rows table calculates its own independently, so editing one row's Acquisition Date or Warranty afterwards only updates that row. Still a normal, directly editable field afterwards — this fills it in rather than locking it, so an unusual warranty term can still be typed over the calculated value.

2.1.0

Accessibility Pass and a Fresher Light Theme

Five improvements from an accessibility and visual-freshness review: (1) the row count, the "missing required fields" count, and the "Not saving" persistence cue now announce themselves to screen readers as they change, instead of updating silently; a duplicate serial number or a missing required field is now exposed to screen readers too (aria-invalid plus a description), not just as a red border only a sighted user would notice; (2) a "Skip to main content" link (the first Tab stop on the page, invisible until focused) lets keyboard and screen reader users jump straight past the header and the full Asset Type menu instead of tabbing through all of it every page load; (3) dialogs and the row-search/bulk-edit/persistence status bars now fade and slide in instead of snapping into view instantly, respecting reduced-motion preferences; (4) an actual contrast audit against every theme turned up three real WCAG AA failures — Windows 3.1's muted text on its teal background, the XP header's white subtitle against its lightest gradient stop, and Dark theme's red "Clear All Rows" button text — all fixed without changing how any theme reads at a glance; (5) Light theme's background is a soft cool blue-gray now instead of a dull khaki-beige, and panels/dialogs in Light and Dark both get a subtle shadow for actual depth instead of a border alone — the five retro skins (Vista/Classic Mac/XP/Windows 3.1/Matrix) are untouched by both changes, each already has its own deliberate look.

2.0.0

Bulk Editing, Themed Dialogs, a Mobile-Friendly Rows Table, and One Settings & Help Menu

The biggest update yet, in one release: the Rows table now has a checkbox on every row (plus a select-all in the header) so one field — Asset State, Cost, Warranty, whatever — can be stamped onto every selected row at once instead of editing each one by hand (e.g. marking 30 rows Retired in one go). Every browser alert()/confirm() (delete a row, Clear All Rows, the 10-product cap, CSV import errors, downloading with missing fields) is now a themed dialog matching whichever of the app's themes is active, instead of a plain OS popup. Below 640px wide, the Rows table switches from a horizontally-scrolling table to a stack of labelled cards, so editing rows on a phone no longer means scrolling sideways through a dozen columns. A search box appears above the table once it has more than 8 rows, filtering by Name/Serial Number/Asset Tag. Importing a CSV via "Import Populated CSV for Editing" now reads extra per-row columns (like Phones & Telephony's Extension) instead of dropping them. Keyboard focus now gets a themed outline everywhere (inputs, selects, buttons) instead of only the theme picker. The persistence-failure warning banner, which only ever showed once and could be dismissed, now has a companion — a small "Not saving" cue next to the row count — that keeps showing up on every failed save even after the banner's gone. And the header's five separate always-visible controls (Leave Feedback, What's New, Help, Install App, Theme) are now behind a single gear icon top-right, opening a "Settings & Help" popout instead of cluttering the header directly.

A new "Open Freshservice to Import" button appears next to Download CSV as soon as you've downloaded a file, opening the Freshservice CMDB Items list in a new tab so you're one click from the Import button (Freshservice's own Import is a JS popup rather than its own page, so this is the closest a link can get you).

0.14.1

Product Catalog Tidy-Up

Synced the Product catalog with a fresh Freshservice export: Printers & Copiers' two e-STUDIO409 models are now named without their serial-number suffixes (e-STUDIO409CS, e-STUDIO409P), and three retired entries (Generic / Text Only, and Other Devices' Monitor and Pro Dock) were removed since they're no longer in the live catalog. EduPC and EduMiniPC now carry their Eduthing manufacturer.

0.14.0

Other Devices Reordered, Extension Set Per Row

Other Devices has moved to the bottom of the side menu (after Servers) — it's a catch-all bucket and shouldn't be anyone's first choice. Phones & Telephony's optional Extension is no longer a single shared value copied onto every row: it's now a genuine per-device field, just like Serial Number. Set it per line in Bulk Add (Name, Serial, Extension) or edit it per row afterwards in the Rows table.

0.13.0

Servers

Servers is now a fully working tab with the standard column set plus Memory(GB) and Disk Space(GB). Only Docking Stations remains "Coming soon."

0.12.0

Network Switches, Phones & Telephony, Printers & Copiers

All three are now fully working tabs with the standard column set (Name, Company, Location, Asset Tag, End of Life, Product, Serial Number, Cost, Warranty (In Months), Asset State, Acquisition Date, Warranty Expiry Date). Phones & Telephony adds an optional Extension field; Printers & Copiers adds an optional IP Address field — both skip the usual required-field check. "Computer (Unspecified)" is removed: its six catalogued products were all actually laptops, so they're now part of the Laptop catalog instead of sitting in their own empty bucket.

0.11.0

Other Devices

"Hardware (Uncategorised)" is renamed to Other Devices and is now a fully working tab — Name, Company, Location, Asset Tag, End of Life, Product, Serial Number, Warranty (In Months), Cost, Asset State, Acquisition Date, and Warranty Expiry Date.

0.10.0

Wi-Fi Access Points

Wi-Fi Access Points is now a fully working tab — Name, Company, Location, Asset Tag, End of Life, Product, Serial Number, Cost, Warranty (In Months), Asset State, Acquisition Date, and a new Warranty Expiry Date field. Works the same as every other asset type: General/Hardware Specific defaults, Bulk Add, Add Assets of Another Product, and Download CSV.

0.9.6

Date Field Height Fix

Fixing the date field width in 0.9.5 traded it for a height regression — removing iOS's native chrome also removed padding/height iOS was adding for free, so Acquisition Date and End of Life rendered shorter than every other field. Every field now has an explicit minimum height instead of relying on padding alone, so this can't happen again for any field, of any type.

0.9.5

Date Field Width Fix, Take Two

The 0.9.2 fix wasn't enough on real iOS Safari — Acquisition Date and End of Life could still render wider than every other field. iOS's native date control apparently ignores min-width/max-width in a grid/flex layout regardless; it now also drops the native chrome (-webkit-appearance: none) in favor of a plainer control that actually respects the page's sizing, while still opening the native date picker when tapped.

0.9.4

Download CSV Moved Below Rows

Moved out of the Rows toolbar to its own full-width button below the table, so it reads as the final step after reviewing your rows rather than one option among several.

0.9.3

Consistent Button Colours

Down to three fills, used consistently everywhere: blue for the default action (Leave Feedback, What's New, Help, Add Assets of Another Product, both CSV imports, Download Template CSV), red for anything destructive (Clear All Rows, deleting a row), and green just for Download CSV — the one "you're done" button.

0.9.2

Date Field Width Fix

Acquisition Date and End of Life could render wider than every other field on some phones (an iOS Safari quirk where a date field's native control refuses to shrink below its own minimum width). Fixed for every field, everywhere.

0.9.1

Mobile Table & Bulk Add Fixes

Name and Delete now stay pinned to the left/right edges of the Rows table while the rest of a row scrolls underneath, so you never lose track of which row you're on or have to scroll past every field to delete one. A bare-serial line pasted alongside Name,Serial lines — usually a forgotten comma — now gets a warning icon instead of silently becoming the Asset Tag. A persistent red count now shows how many rows are missing required fields. Input borders and the required-field marker are also easier to spot.
