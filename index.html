Help Guide

Theme

The Theme dropdown in the header switches between System (follows your OS/browser setting), Light, Dark, and five retro skins — Vista, Classic Mac, XP, Windows 3.1, and Matrix — each a full visual reskin rather than just a color swap. Matrix also animates a dimmed, throttled falling-character canvas behind everything; it pauses when the tab isn't visible and skips entirely if you have reduced motion enabled system-wide. Your choice is remembered and applied before the page paints on your next visit.

1. Pick an asset type

Use the menu on the left (or the "Asset Type" button on mobile) to choose what you're importing — Monitor, Laptop, Desktop, iPads / Tablets, Interactive Touchscreen, Wi-Fi Access Points, Network Switches, Phones & Telephony, Printers & Copiers, Servers, Docking Stations, or Other Devices. A note at the bottom of the list points at Leave Feedback for requesting any type that isn't here yet.

2. Fill in General

Company and Location are both dropdowns, not free text. Company lists every known site; picking one narrows Location down to just that site's own sub-locations, defaulting to the site's own name until you pick something more specific. These are copied onto every row you add, and each row can still be edited individually afterwards.

3. Fill in Hardware Specific

Fields marked with a red * are required. Start typing in Product to see suggestions, or narrow them first with the Manufacturer dropdown above it. Picking a known product auto-fills its Warranty and other specs.

4. Bulk Add from Serial Numbers

Paste one asset per line into the box:

  • A bare serial number — the Name will default to the Asset Tag
  • Name, Serial (or paste two columns from a spreadsheet) to set the name yourself

Asset types with an extra per-device field (currently Phones & Telephony's Extension) accept it as a trailing value on the same line — Name, Serial, Extension — instead of one shared value copied onto every row; leave it off a line if you don't have it yet.

Or click Import CSV to load a Name/Serial file directly — use Download Template CSV first if you're not sure of the format.

If a bare-serial line shows up alongside Name, Serial lines, it's marked with ⚠ in the preview and Rows table — usually a forgotten comma, so double-check the Name before downloading. Editing that row's Name clears the warning.

5. Asset Tag

Generated automatically as <site code>-<serial> from the Company you've selected — you never type it by hand.

6. Add Assets of Another Product

Its live preview shows exactly what clicking the button will add to the Rows table below. Rows accumulate rather than replacing what's there — to mix another product into the same export, change the Product/Hardware Specific details above and click Add Assets of Another Product again before downloading. Each export can hold up to 10 different products; you can fine-tune any field per row afterwards.

7. Download CSV

Produces a CSV with the exact column order Freshservice expects for the selected asset type, ready to import. If any rows are missing required fields, a red count stays next to the row total in Rows until they're fixed — not just a one-time warning when you click Download. Once you've downloaded, an Open Freshservice to Import button appears alongside it — it opens the Freshservice CMDB Items list in a new tab, which is where Freshservice's own Import button lives (it's a popup, not a page of its own, so this is as close as a link can get you).

Editing an existing export

Import Populated CSV for Editing, above the Rows table, loads a full CSV — every column, not just Name/Serial — straight into the table so you can tweak an export you already made and re-download it. It matches columns by header text, so unrecognised columns are ignored and missing ones are left blank; imported rows are added alongside whatever's already there.

Your data

Everything stays in this browser's local storage on this device — nothing is uploaded anywhere. Closing the tab is safe; clearing site data is not.

TV / Digital Signage Manufacturer Filter

TV / Digital Signage is now a fully working tab — Name, Company, Location, Asset Tag, End of Life, Product, Serial Number, Cost, Warranty (In Months), Asset State, Acquisition Date, Warranty Expiry Date, and Screen Size (In Inches), the same way Monitor has its own Monitor Size field.

1.7.0

Moved to a New Domain

Moved hosting to a new domain.

1.6.0

Company and Location Are Now Both Dropdowns

Company and Location are no longer free text — both are closed dropdowns now, in the Defaults panel and per row in the Rows table alike. Picking a Company narrows Location down to just that site's own sub-locations (generated from a Freshservice Locations export), defaulting to the site itself until you pick something more specific; changing Company resets Location back to that default, since a previously-picked sub-location almost never still applies once the option list underneath it has changed. Also removed the dropdown arrow from Processor and every other typed-history-only field (added broadly in 1.5.1) — it's kept only on Product now, the one field actually backed by a real curated catalog; an arrow on a field that's just remembered whatever you've typed before was misleading.

1.5.2

Dropdown Arrow Size Fix

The dropdown arrow added in 1.5.1 to Company/Product/suggestion fields was noticeably chunkier than the native arrow on a real <select> like Manufacturer or Asset State, right next to it in the same form. Shrunk it down to match.

1.5.1

Dropdown Arrow on Company/Product/Suggestion Fields

Company, Product, and every other suggestion-backed field now show a small dropdown arrow, matching what a native <select> like Asset State already shows for free — without it, these fields read as ordinary free text with no hint they have a list to open. Also fixed the Compiled date, which hadn't been bumped for a day.

1.5.0

Docking Stations, and a Way to Request New Types

Docking Stations is now a fully working tab with the standard column set (Name, Company, Location, Asset Tag, Product, Serial Number, Cost, Asset State, Acquisition Date, Warranty (In Months), Warranty Expiry Date, End of Life) — the last "Coming soon" placeholder is gone; every real Freshservice Asset Type now has a template. In its place, a non-clickable note at the bottom of the Asset Type menu points at Leave Feedback for requesting any type that shows up in a future export and isn't here yet.

1.4.3

Sidebar Icons Left-Aligned Again

Found the actual cause of the sidebar's centering issue: a global rule centers icon+text in every button (correct for Download CSV, Add Assets of Another Product, etc.), and the side nav's tabs are buttons too, so they'd been silently inheriting that centering for a while now — invisible for short single-line labels, but visibly inconsistent for two-line ones like Interactive Touchscreen and Docking Stations. Tabs are back to a proper left-aligned list, matching every other nav item regardless of label length.

1.4.2

Company Dropdown Restored

Company now has a dropdown of every known site again — click in to see the full list, or type to filter it. This was a real dropdown (a native <select>) once, dropped in v0.8.0 in favor of free text with typed-history suggestions only; it's back now using the same reliable combobox already used for Product, rather than the old native select. Typing a site not yet in the list is still remembered for next time. Location stays exactly as it's been — auto-filled from a matching site but always freely editable, since it's expected to grow to hundreds of values that don't each need a catalog entry.

1.4.1

Open Freshservice Button Width Fix

"Open Freshservice to Import" was narrower than Download CSV above it — it never got the full-width sizing added for Download CSV, so it fell back to default content-width and only looked full-width by coincidence (wrapping onto its own line below Download CSV's own full-width box). Both buttons now share the same width rule explicitly.

A sixth Theme option: a black/green terminal skin (monospace type, glowing outline buttons) with a falling-character canvas animating behind everything. Kept deliberately restrained since it's the first animated theme — dimmed and throttled well below 60fps, paused automatically whenever the tab isn't visible, and skipped entirely under prefers-reduced-motion, so it stays background ambience rather than competing with actually using the app.

0.16.7

Icon Cache-Busting Fix

The browser tab (favicon), Home Screen, and PWA install icon files kept the same filenames across every recent icon redesign, so browsers that had already cached an older version had no reason to notice the new one — favicons are cached far more stubbornly than normal page assets, sometimes for days. All icon/manifest links now carry the same ?v= cache-busting already used for CSS/JS, so icon updates take effect immediately going forward.
